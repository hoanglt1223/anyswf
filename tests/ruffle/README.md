# Ruffle test movies

Each `*/test.swf` here is copied unmodified from Ruffle's test suite
(`tests/tests/swfs/<path>/test.swf` at Ruffle commit
`8b25621fc7096de700830d4764bfd1f7585c73d5`). Directory names are the original path with
`/` replaced by `_` (the `visual/` prefix dropped). Ruffle is dual licensed MIT OR
Apache-2.0; see [LICENSE.md](LICENSE.md). Copyright (c) 2018-2022 Ruffle LLC and Ruffle
contributors.

They are used by the render tests (`tests/render/`) and, for ActionScript tests, by the
AVM1 conformance runner.
