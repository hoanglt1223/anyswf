# Ruffle AVM1 test movies

Each directory here is copied unmodified from Ruffle's test suite
(`tests/tests/swfs/avm1/<name>/` at Ruffle commit
`8b25621fc7096de700830d4764bfd1f7585c73d5`): `test.swf`, the Flash Player trace in
`output.txt`, `test.toml`, and the `.fla` source where Ruffle has one. These are the 199
tests the AVM1 runner (`tests/avm1/run-avm1-tests.py`) statically selects. Ruffle is dual
